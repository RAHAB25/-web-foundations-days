About QuickNotes

QuickNotes is a simple web application that allows you to quickly jot down your ideas and keep track of them.
It is designed to be lightweight and easy to use, so you can focus on capturing your thoughts without any distractions.

How to use QuickNotes

  1. Type your note in the input field.
  2. Click the "Add Note" button to save it.
  3. Your notes will be displayed in the list below.

Features

  • Quickly add and save notes
  • View your list of notes
  • Simple and user-friendly interface

Keyboard Shortcuts

Shortcut Action
Ctrl + N Add a new note
Ctrl + D Delete the selected note
Ctrl + S Save your notes
